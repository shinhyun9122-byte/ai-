# 부지검토서 생성기 업데이트

## 최신 수정본 — 모든 연료전지 용량 지원

[generator-capacity-review.zip 다운로드](./generator-capacity-review.zip)

12페이지 산출 요약의 세 항목이 회색 네모 박스 안에 들어가도록 글자 크기를 자동 조정했습니다. 고정 배치 페이지의 하단 출처가 자동 분할되면서 생기던 빈 페이지 두 장(기존 13·14페이지)도 생성되지 않도록 수정했습니다. 숨겨진 페이지는 자동 분할 대상에서 제외합니다. 브라우저 미리보기와 PDF 출력을 확인했습니다.

제공 PDF 10페이지를 기준으로 산출 페이지의 글자 크기·색상과 배치를 재조정했습니다. 본문 약 16pt, 점수·하단 설명 파랑(#0000FF), 제목 약 20pt 주황(#FE6202), 소제목 약 17pt로 맞추고 회색 박스·그래프·배점표 배치를 정리했습니다. PDF 저장 결과의 색상·크기와 1페이지 내 배치를 확인했습니다. 수치와 계산식은 유지합니다.

변전소 현황 이미지를 요청한 예시 양식에 맞춰 범례 4개, 가로 그래프 3개, 변전소 그래프 전체·해설 첫 줄 강조, 둥근 회색 테두리로 수정했습니다. 숫자는 실제 조회 데이터로 생성하며 사진의 일산변전소 값을 고정하지 않았습니다. 실제 보고서 렌더링과 페이지 영역 내 배치를 확인했습니다.

한전 원자료 표와 보고서 변전소 현황에 원본 조회 링크와 대조할 주소/전주번호를 추가했습니다. 주소 조회·전주번호 조회·월보 출처를 연결하고, 전주 위치 검색(ElecMap) 및 프로그램 계산 점수와 구분합니다.

변전소 현황의 범례·해설과 관련 화면 표기를 기존 검토서에 맞춰 **접수기준 접속용량**으로 통일했습니다. 수집 수치와 계산 방식은 유지했습니다.

필지 조회 후 자동 계통평가 시작·계통평가 화면 열기·보고서 작성 시 월보를 자동 조회합니다. 수동 다시 조회 버튼은 재시도용입니다. 전주 조회 실패 후 주소 조회로 전환할 때 조회 근거가 잘못 남는 문제를 수정하고, 반환된 변전소 후보와 자동 선택 기준을 표시합니다. 표시 변전소는 접속 후보이며 실제 접속점 확정을 뜻하지 않습니다.

최신 보완: 자동 접속 검토안의 예상 점수를 배점표·예상 총점·상세 보고서에 반영합니다. 연계 방식 칸에도 자동 선택 결과와 점수를 표시합니다. 한전 조회의 파랑/초록 접속용량·각 여유용량, 조회 대상·시각을 구분하고 명시적 다시 조회는 캐시를 건너뜁니다. 재조회 실패 시 이전 용량을 지웁니다. 실제 보고서 화면의 자동 배점과 기존 월보 테스트를 검증했습니다.

접속검토자료 등록·불러오기·저장 기능을 제거했습니다. 자료를 등록할 필요 없이 필지 주소와 연료전지 용량을 입력하면 자동 검토안·조건부 예상 점수를 볼 수 있습니다. 기존에 저장한 접속자료는 더 이상 자동 적용하지 않습니다.

필지 주소를 조회하고 설비용량(MW)을 입력하면, 3MW 한정 없이 용량별 초기 접속 검토안과 조건부 예상 점수를 표시합니다. 한전 공개 연계기술 기준과 송·배전용 전기설비 이용규정을 참고했습니다. 저압 500kW 미만, 공용선로 검토 10MW 이하, 전용선로 구성의 20MW 경계 및 배점표의 40MW 초과 조건을 구분합니다. 선로 또는 상위 계통 여유용량 부족, 자료 미확인, 다른 지번의 참고 결과와 기술 검토 조건을 표시합니다. 한전 접속 승인이나 확정 점수가 아니며, 전용 1회선은 조건부 대안으로 표시합니다.

기존 폴더를 백업한 뒤 ZIP의 `server.py`와 `부지검토서_생성기.html`을 교체하고 서버를 재시작하세요. `.env`, `templates`, `start.bat`은 유지하세요. ZIP에는 실행 파일 두 개와 사용안내·근거 문서만 포함했습니다.

용량 경계값 16개와 입력 변경·여유용량·자료 우선순위·보고서 스크립트 검증, 기존 월보 테스트 8개 및 브라우저 회귀 검증을 통과했습니다. Windows 실행과 전체 출력은 이번 검증 범위 밖입니다.


## 다운로드 및 실행

1. 저장소의 **generator-update.zip**을 클릭하고 **Download raw file**로 다운로드합니다.
2. 기존 프로그램 폴더를 백업합니다.
3. ZIP의 `server.py`와 `부지검토서_생성기.html`을 기존 프로그램 폴더에 덮어씁니다.
4. PC의 기존 `start.bat`을 그대로 더블클릭합니다. `.env`, `templates` 등 기존 설정과 파일은 유지하세요.

개인 API 키 보호를 위해 `start.bat`은 이 저장소에 올리지 않았습니다. 이미 사용 중인 실행파일을 그대로 사용하면 됩니다. Python 3.10 이상이 필요하며 월보 기능에 추가 패키지는 필요 없습니다.

## 변경 사항

검토서 작성 때마다 한전 공식 전력통계월보의 최신 게시물과 Excel을 조회해 12쪽 지역수급비율 표, 관련 배점 및 출처·기준연월·조회시각을 함께 갱신합니다. 같은 연월의 **월간** 발전량·판매량으로 계산하며 발전량 GWh를 MWh로 환산합니다. 고정된 2024년 값은 사용하지 않습니다.

조회 실패 시 이전 수치로 조용히 대체하지 않고 확인 필요로 표시합니다. 직접 내려받은 월보 XLSX를 계통평가 화면에서 불러올 수도 있으며 이 경우 최신 여부 미확인으로 표시합니다.

2026년 7월부터 원자료에서 전남·광주가 통합 집계되므로 통합 지역을 표시하며, 개별 전남·광주 부지의 배점은 임의 확정하지 않습니다. 입찰 공고가 연간 등 별도의 적용 기간을 정한 경우 확인이 필요합니다.

## 검증

- 실제 한전 게시판과 Excel 다운로드 및 서버 API 검증: 확인 시 최신 게시물은 2026년 8월호(제574호), 16개 집계지역.
- 월보 처리 테스트 6개 및 Chromium에서 표·출처·배점 반영과 조회 실패 처리 검증.
- Windows `start.bat` 실행 자체는 Linux 환경에서 시험하지 못했습니다. 기존 배치파일과 동일한 서버 파일명 및 실행 구조를 유지했습니다.

최초 클라우드 한전 요청의 403은 해당 환경의 외부접속 프록시에서 발생했으며, 이후 접속에 성공해 실사이트 검증을 완료했습니다. 사용자 PC의 접속 가능 여부는 해당 PC의 네트워크에 따릅니다.


## 3MW 연료전지 초기 검토안 수정본

[generator-3mw-review.zip 다운로드](./generator-3mw-review.zip)

기존 프로그램 폴더를 백업하고, ZIP의 `server.py`와 `부지검토서_생성기.html`을 교체한 뒤 서버를 다시 실행하세요. 기존 `.env`, `templates`, `start.bat`은 유지하세요. 상세 사용법은 ZIP의 `사용안내.md`를 참고하세요.

설비용량 기본값은 3MW입니다. 접속검토 자료가 없으면 22.9kV 공용선로를 사용하는 초기 설계 가정의 예상 10점을 별도로 표시하며, 확정 배점·총점에는 합산하지 않습니다. 이는 한전의 접속 가능 판정이 아닙니다. 후보 선로의 표시 여유용량이 3,000kW 미만이면 이 안을 보류합니다. 해당 필지의 정보가 없으면 자료 미확인으로 표시하며, 다른 지번이나 최근접 전주의 결과는 참고 정보로 구분합니다.

월보 처리 테스트 8개와 Chromium에서 배점·자료 반영·초기 검토안 검증을 통과했습니다. Windows 실행과 전체 문서 출력은 이번 검증 범위에 포함하지 않았습니다.
